# Alesja Deliu — Marketing Portfolio

Website statik: HTML, CSS dhe JavaScript. Nuk kerkon instalim ose build.

## Hape ne VS Code
1. Shpaketo ZIP-in.
2. Hap dosjen `alesja-deliu-portfolio` me File > Open Folder.
3. Hap `index.html` ne shfletues ose me Live Server, nese e ke te instaluar.

## Skedaret
- `index.html`: tekstet, statistikat dhe struktura.
- `style.css`: dizajni dhe pershtatja per telefon.
- `script.js`: galeria e videove dhe zmadhimi i screenshot-eve.
- `images/`: statistikat e reja te Meta Ads dhe Insights.
- `videos/`: videot dhe pamjet paraprake.
- `Alesja-Deliu-CV.pdf`: CV-ja e shkarkueshme.

## GitHub
Ngarko permbajtjen e kesaj dosjeje ne repository, duke mbajtur `index.html` ne nivelin kryesor dhe duke ruajtur emrat e dosjeve. Mos ngarko vetem ZIP-in. Website-i eshte i pershtatshem per GitHub Pages.

Renditja: prezantimi dhe About me, statistikat ekzistuese, Meta Ads, Facebook/Instagram Insights, videot, eventet, eksperienca dhe kontakti.

Meta Ads: $60 per 30 reklama, sipas screenshot-it te konfirmuar. Statistikat fillestare jane ruajtur. Fotografia eshte kompakte ne prezantim. Asnje link video nuk varet nga faqja private e ChatGPT; videot jane skedare lokale brenda projektit.
